# 💪 Fitness Website

A modern, responsive fitness web application built with vanilla JavaScript, CSS, and HTML. This platform helps users discover fitness resources, track their wellness journey, and access valuable fitness information.

---

## ✨ Features

- **Responsive Design** - Seamlessly adapts to all device sizes (mobile, tablet, desktop)
- **Interactive UI** - Smooth animations and intuitive user interface
- **Modern Styling** - Clean, professional CSS styling with excellent visual hierarchy
- **User-Friendly** - Optimized for ease of use and accessibility
- **Fast Performance** - Lightweight codebase with optimized assets

---

## 🛠️ Technology Stack

| Technology | Usage | Percentage |
|-----------|-------|-----------|
| **JavaScript** | Core functionality & interactivity | 93.5% |
| **CSS** | Styling & responsive design | 6% |
| **HTML** | Semantic structure & markup | 0.5% |

## 📦 Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/mAbdullah02-bit/Fitness-website.git
   cd Fitness-website
   ```

2. **Open in your browser**
   - Simply open `index.html` in your preferred web browser
   - Or use a local server:
     ```bash
     python -m http.server 8000
     # Then visit http://localhost:8000
     ```

---

## 🚀 Quick Start

1. Open the project folder
